# 角色动画与装饰扩展

角色渲染位于 `src/components/avatar/`，复用项目已有 Motion，不新增运行时库。AIPP 资产与动作自行编写，没有引入参考项目的播放器或提取动作数据。

## 形象定义

`avatarDefinition.ts` 注册形象。每个形象使用 510 单位坐标系，提供：

- `parts`：分层轮廓和颜色槽，当前协议支持 primary/secondary 两个颜色槽；需要更多槽时应升级配置协议。
- `face`：双眼中心与缩放，眼镜挂在同一位置。
- `crown`：帽子位置与缩放。
- `propDock`：摘下眼镜时的停靠位置、缩放和角度。
- `capabilities`：是否支持眼部装饰和头饰。
- `colorLabels`：编辑器的颜色区域名称。

新增形象要注册类型与定义、校准锚点，验证大预览与 22px/32px/44px 显示。第二形象圆团已复用同一渲染器与动作，未新增分支坐标。当前只接受随应用内置的定义，不支持任意 SVG 上传后自动绑定动画。

## 动作与装饰

`AnimatedAvatar` 将身体、眼睛、眼镜和帽子分层渲染。装饰跟随身体变换；眼镜脱离面部后仍在角色的局部坐标系内移动。每个实例的渐变 ID 使用 React useId 隔离。

`AvatarAccessories.tsx` 保存装饰图形；`accessoryDefinitions` 描述挂载槽、能力要求和动作。当前内置眼镜、帽子两个槽；增加新的槽或新的装饰类型需要同时扩展配置验证、渲染和编辑器，不是任意素材自动适配。

运行状态优先于一次性表演：状态切换、关闭动画、离屏和页面隐藏会取消表演。`useAvatarMotion` 清理定时器与可见性观察器；再次显示不会重播旧请求。摘戴表演不改变持久化配置，移除装饰则改变编辑草稿。AIPP 无手部，摘戴采用悬浮移动方式。

播放器使用原创关键帧片段、三次贝塞尔插值、种子洗牌与姿态过渡；提供 53 种语义状态和 28 个动作片段。大预览显示完整动作与程序图形；小于 48px 的头像保留身体、眼睛表情，缩小位移且不显示遮挡形象的功能图形。联系人列表启用状态动画，往来记录保持静态。运行中组件仅以 Motion 驱动每帧变换，不通过 React state 每帧更新。

## 会话状态

`useConversationAvatarState` 订阅当前 `conversation_event_<id>`，建立监听后读取运行态快照，避免旧查询覆盖实时事件。使用 epoch/revision 排除旧快照。user_pending 对应思考，mcp_executing 对应执行，assistant_streaming 对应回复，等待交互覆盖为等待。明确 stream_complete 才触发短暂完成反馈，错误和取消会阻止该反馈。

## 联系人状态聚合

`list_butler_contact_activity` 在后台线程读取主会话、长期私聊、全部派发任务归属，再合并运行态、Operation/ACP 审批、ask_user_question/ACP elicitation 和协作请求等待状态。它独立于任务面板的分页，不创建新会话、不调用模型。

`useContactAvatarActivity` 按 assistant_id 聚合，订阅非终态会话与任务/协作变更，每两秒校准一次快照；页面隐藏时暂停查询。终态任务不保留会话事件监听。运行态以 epoch/revision 防止旧快照回退；挂载时只建立历史基线。

- 优先级：待审批 → 等你回答 → 新错误 → 工具执行/回复 → 等待协作 → 思考/任务处理 → 完成或未读短反馈 → 进入/悬停 → 空闲。
- 新失败短暂播放 failed，然后保留“执行出错”；点击联系人或新一轮运行清除提示。取消、中断不播放 finished。
- 完成/失败/未读反馈窗口约 3.5 秒，由两秒校准定时器回收；有其他运行任务时优先展示运行状态。
- 空闲悬停播放 curious；点击进入短暂 listening；新未读通知只对基线之后的新消息触发，未读点仍由阅读进度决定。
- 32/44px 联系人头像保留形状与配色，状态文字承担精确区分；未配置外观的普通助手用原有颜色的圆团参与动画。

动作关闭、减少动态效果、离屏时停止视觉运动，状态文字仍更新。活动查询/订阅诊断保留在控制台，不在联系人列表展示原始错误；查询失败不覆盖已有活动快照。没有助手归属的历史联系人/任务不参与聚合，主会话仍独立映射到总管家。悬停只触发状态机的好奇动作，不再强制微笑。

## 持久化与验证

`butlerAppearance.ts` 将无版本的 shape/left/right 配置读取为 v2；v2 保存 shape/colors/accessories/motion。打开弹窗不会写回，只有保存才持久化。恢复黑白不清除装饰与形状。

定向测试覆盖迁移、非法配置、配色/装饰保存、取消、错误保留草稿、动作中断、减少动态效果、多实例资源隔离、运行态顺序与取消/错误事件。实际视觉验收应在构建后的应用中检查普通/深色主题、眼镜摘戴全程、帽子边界和长对话滚动。
