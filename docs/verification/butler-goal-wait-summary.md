# 管家目标、等待问题和摘要

## 使用

管家主窗口、成员窗口、独立任务窗口的输入框上方可选择消息用途：
- 补充要求：在原要求上增加内容。
- 更改目标：以本条要求为准，旧执行不能提交新的结果或工具操作。
- 旁问：询问其他问题，不改原目标。首次尚无目标时，以这条消息建立初始目标。
- 停止当前工作：先保存停止状态，再请求取消运行。

默认选择“补充要求”。普通聊天不显示此选择。已有资料和原文保留；未完成的旧回复单独标记，已结束的历史报告不改正文。

问题保存 24 小时。重开会话可看到尚有效的问题；回答关联原问题和目标版本，不创建新独立任务。过期、重复回答、目标已经变化的答案不会续办。敏感答案不从重启恢复入口保存。原执行存在结果不明的工具操作时，不自动续办，需先核对结果。

摘要保存当前目标、未答问题、授权来源限制。生成期间或读取前目标、问题发生变化时，拒绝旧摘要并使用原记录。摘要与历史文字不能代替本次批准。

## 复测

1. 在管家开始处理后，连续两次选择“更改目标”发送相反要求。以最后一次为准，旧执行不可继续提交，历史资料仍在。
2. 发一条“旁问”，确认原工作目标未被替换。停止后刷新窗口，旧执行不能恢复。
3. 等助手提问后退出再进入会话，回答仍有效的问题。重复提交不能生成第二次执行。
4. 提问后更改目标，再提交旧答案，应被拒绝。另一个独立任务不受影响。
5. 在长会话压缩期间更改目标，不能采用旧摘要；回答问题后也不能把“待回答”旧状态作为现状。

## 自动验证范围

内存数据库测试涵盖目标连续变更、旁问与停止、原文保留、已完成历史报告保持不变、问题到期和重复恢复、敏感答案拒绝、任务隔离、迟到问题、摘要读取校验、排队失败回滚。前端测试涵盖四种消息用途与原引用信息。

真实模型、桌面重启和外部服务副作用仍需端到端验收，不能以单元测试代替。
