## 设备测试发现的问题

- Android CSP 的 `script-src` 原本未允许 `convertFileSrc` 使用的 `http://asset.localhost`，导致已启用 JS 插件无法加载。已修复并通过设备验证，提交 `95ba6ea`；资产访问仍受私有目录 scope 限制。
- 定时任务旧表的状态 CHECK 约束不接受 `missed`，启动时写入错过记录失败并回滚。简化内存表的调度回归未发现此问题。已补保留列、数据、索引、触发器和自增序号的迁移及真实建表回归，提交 `f78c4a3`，旧库设备升级通过。
