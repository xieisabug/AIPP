# 管家增强验收矩阵

本矩阵仅覆盖管家主会话、联系人成员、独立任务和明确绑定管家的后台检查。普通聊天作为权限不泄漏的兼容用例。外部渠道、尚未实现的产品协作群不属于本轮已验证能力。

| 范围 | 关键异常场景 | 通过依据 |
| --- | --- | --- |
| 最新要求与摘要 | 连续改目标、旁问、停止、压缩期间改目标、旧输出 | 目标修订号、摘要检查点与执行校验回归 |
| 等待问题 | 重启、旧题目/旧版本/过期答案、重复答复、并行其他工作 | 持久等待记录与真实内存数据库回归 |
| 批准 | 改目标/参数/接收人、过期、重复消费、仅模型声称批准 | 具体操作批准绑定及执行门校验 |
| 执行控制 | 暂停/恢复、停止后续、整链停止、迟到结果、并行兄弟工作 | 控制状态、执行账本与取消回归 |
| 回报与进展 | 重启、重复回报、未知结果、待答对象与成果证据 | 持久状态与前端卡片测试 |
| 后台检查 | 未授权来源、过期、停用、只读/草稿、普通日程不受影响 | 持久策略及调度/工具执行前校验 |
| 能力回退 | 四开关独立、已排队暂停、保留取消与读取、恢复不过期授权 | 能力解析、配置持久化及生产入口检查 |

执行顺序：先本地只读与模拟服务，再隔离工作区文件操作，最后在另行具备授权和真实外部测试条件时测试外部提交。不得通过切换模型、清空用户数据或重复不确定外部动作让测试“通过”。

测试结果与未测限制以 PR 验证记录为准；本矩阵不是已经完成所有设备和外部服务验收的声明。
