# Artifact 预览与执行

Artifact 预览与执行模块允许 AI 生成的内容（HTML、SVG、XML、Markdown、Mermaid、Drawio、React/Vue 组件、Python 脚本等）在独立窗口中实时预览和执行。

---

## HTML/SVG/XML 预览

### HTML 内容预览
- 自动检测消息中的 HTML 代码块
- 支持内联样式和外部资源引用
- 在 Artifact Preview 窗口中渲染
- 实时更新内容变化

### 外部资源授权
- 预览引用的远程图片、样式表、字体、脚本等默认不加载，点「加载外部资源」逐项查看完整地址、类型、风险和出处（例如「由样式表 cdn.jsdelivr.net/…/index.css 引用」；样式表里的相对路径悬浮可见原写法）
- 勾选后由本机下载再提供给预览：「允许本次加载」只对当前预览生效，「加入白名单并加载」按域名和类型记住，「使用代理加载」需先在 设置 → 网络配置 填写代理，未配置时按钮不可用
- 允许（或白名单放行）一个样式表时，它引用的字体、图片、音视频和子样式表一并加载，不再追加第二轮授权；脚本、网页等仍需单独授权
- `.woff`、`.woff2`、`.ttf`、`.otf`、`.eot` 一律按字体处理；`@font-face` 里没有扩展名的地址也按字体处理
- 无法解析的地址（如缺少基准地址的相对路径）单独列出，不可勾选，也不会让弹窗反复出现

### SVG 渲染
- 支持 SVG 代码块渲染
- 矢量图形无损显示
- 支持动画 SVG

### XML 渲染
- 支持 XML 代码块格式化显示
- XML 语法高亮
- 结构化展示

### Markdown/Mermaid 渲染
- 支持 Markdown 文档渲染
- 支持 Mermaid 图表渲染
- 流程图、时序图、甘特图等
- 实时渲染更新

### Drawio 图表渲染
- 支持 Drawio 图表渲染
- Drawio 图表文件预览
- 标为 `xml` 的内容若以 `<mxfile>` 根元素开头，也会自动使用 Drawio 预览；支持前导空白、BOM、XML 声明和注释
- 矢量图形显示

### 独立预览窗口
- Artifact Preview 专用窗口
- 可调整大小
- 支持全屏预览

### 统一查看器
- 预览窗口、侧栏窗口和收藏窗口使用同一个查看器（`src/components/artifact/ArtifactViewer.tsx`），会话状态由 `useArtifactPreviewSession` 统一处理
- 工具栏提供：复制代码、导出（保存源文件；Mermaid/SVG 可导出 SVG 图片）、重新加载、在浏览器打开（React/Vue）、全屏（侧栏为「在预览窗口打开」），以及「预览 / 代码 / 控制台」三个视图
- 切换到代码或控制台视图时，预览页面保持运行，不会重新加载
- 用户页面（HTML/SVG/XML/React/Vue）一律以白底显示，与浏览器默认一致，深色主题下也能看清
- 侧栏、预览窗口和聊天窗口分栏各自使用独立的 React/Vue 预览实例，互不关闭对方
- 预览事件只投递给目标窗口：后端 `emit_to(窗口标签)`，前端 `useArtifactEvents` 按本窗口标签监听（Tauri 里不带目标的 `listen` 会收到所有窗口的事件），几处预览互不串内容；安装完成这类全局事件照常收到

### 聊天窗口分栏
- 桌面聊天窗口里点消息的「运行」、侧栏 Artifact 列表或聊天里的 Artifact 成果卡，预览显示在聊天窗口右侧的分栏，边对话边看效果，不再另开预览窗口。窗口宽度不足 900 时仍用独立预览窗口；比选卡的「独立窗口打开」不变
- 分栏左边缘可拖动调宽（至少 360，给会话留至少 420），宽度记在本机。工具栏末尾有「关闭预览」，「在预览窗口打开」把当前内容移到独立预览窗口（`pop_out_artifact_preview`）
- 开关分栏不会重建会话界面。Windows 的窗口按钮在分栏打开时移到分栏工具栏末尾
- 分栏卸载时结束它的 React/Vue 预览服务。它不注册窗口的关闭回调：Tauri 的 `onCloseRequested` 处理完会销毁窗口，而聊天窗口关闭只是隐藏（`useArtifactPreviewSession` 的 `stopOnWindowClose: false`）
- 实现：`artifactPane.ts`（只有聊天窗口启用，预览入口用 `artifactPreviewTarget()` 取 `sourceWindow`）、`ChatArtifactPane.tsx`、`EmbeddedArtifactPreview` 的 `windowLabel="chat_ui"`；后端 `preview_router` 把 `chat_ui` 当作嵌入式目标

### 与上一版对比
- 有上一版时，代码视图顶部有「对比 vN」。打开后逐行显示当前版本与上一版的差异（+ 新增、- 删除，灰度标出），并汇总增删行数；多文件版本按所选文件对比，上一版没有该文件时整份算新增
- 中段差异过大（行数乘积超过 400 万）时不再逐行对齐，显示整段删除与新增。实现见 `src/components/artifact/lineDiff.ts`

### 控制台与「让 AI 修复」
- 控制台汇总构建日志与页面运行输出：`console` 输出、未捕获异常、未处理的 Promise 拒绝、资源加载失败，以及 Vite 编译错误
- 采集脚本是 `src-tauri/artifacts/runtime/aipp-console.js`。HTML 预览时把它内联到页面最前面，并压成一行，所以报错行号与原文件一致；React/Vue 模板在 `index.html` 里最先加载它
- 页面运行出错时，预览底部出现提示条，控制台标签显示错误数
- 「让 AI 修复」把去重后的错误整理成一段说明，填进该 Artifact 所在会话的输入框，并把聊天窗口提到前台。这一步不会自动发送，用户可以补充后再发。没有窗口打开该会话时，会提示先打开原会话
- 收藏窗口里的 Artifact：从会话收藏的（记有来源）交回原会话；原会话没打开时先在聊天窗口打开，再填入输入框。没有来源的收藏不提供此操作

### 选择元素修改
- 工具栏的「选择元素修改」按钮让预览页面进入点选模式：悬停的元素加描边，点击后不会触发页面自身的点击，按 Esc 取消。HTML、React、Vue 和多文件工程可用；需要有能接收的会话（与「让 AI 修复」相同）
- 点中后，预览底部出现输入框，显示元素标签、定位路径和文字。写下修改要求后点「填入会话」（Ctrl/⌘+Enter），AIPP 把 Artifact 名称、版本、元素定位和渲染出的 HTML 片段整理成一段说明，填进原会话输入框，同样不自动发送
- 点选由同一个采集脚本 `aipp-console.js` 实现，只接受父窗口发来的指令。定位路径优先用元素 id（只认合法标识，React `useId` 生成的 `:r0:` 这类不用），否则按标签、简单类名和同级序号拼出最多 6 层；Tailwind 这类带 `:`、`/` 的类名不计入
- 元素截图：会话 Artifact 看最新版本时，点中元素后就在后台用无头浏览器截取这个元素（`capture_artifact_element`，截图请求的 `clip_selector`），提交时最多等 20 秒，截到就作为图片附件和说明一起加进输入框，说明里注明「截图：见附件」；截图失败只附带定位。旧版本、收藏和无会话的预览不截图

### 发布后运行检查
- `show_artifact` 发布后默认在后台无头浏览器里加载一次预览，并把结果写进返回值的 `diagnostics`：`ok` 表示无报错；`errors` 表示有报错，同时列出错误与警告，各最多 20 条；`skipped` 表示未能检查，原因写在 `note`
- HTML/SVG/XML 直接加载；React/Vue 复用截图用的模板目录启动预览，和截图一样同一时间只跑一个。Markdown 为静态内容，不检查
- 检查最长 30 秒。没有 Chromium、预览服务未能启动或超时时，结果为 `skipped`，不影响发布
- 模型可以传 `check: false` 跳过检查
- 聊天里的 Artifact 卡片在检查发现错误时标出错误数

## Artifact 集合管理

### Artifact 创建与保存
- `artifacts_db.rs` 管理 Artifact 数据库
- 保存 AI 生成的 Artifact
- Artifact 元数据存储

### Artifact 自有数据
- `artifact_data_db.rs` 为 Artifact 提供独立 SQLite 数据库（`<应用数据>/artifact_data/<db_id>.db`），供 Artifact 页面经桥接 API 读写自己的数据；不存放 Artifact 代码

### 收藏
- `collection_api.rs` 管理收藏（单表 `artifacts_collection`，不分组）
- 收藏保存名称、图标、描述、标签、代码以及数据库/助手绑定
- 打开收藏项支持 React、Vue、HTML、SVG、XML、Markdown、Mermaid；绑定的数据库与助手随之生效

### 收藏 UI
- Artifact 合集窗口：图标网格；搜索名称、描述和标签；有两种以上类型时可按类型筛选，有标签时显示标签筛选；排序可选「最常用」（默认，使用次数）、「最近使用」、「最新收藏」
- 卡片悬停或键盘聚焦时显示「回到原会话继续修改」（有来源时）、「编辑」、「删除」；右键菜单保留同样的操作
- 标签字段兼容逗号（中英文）、顿号、分号分隔的文本和旧的 JSON 数组
- 打开收藏项时复用同一个预览窗口，标题随所打开的项更新；切换或关闭时结束上一项的预览服务；每次打开记一次使用（次数与时间）
- 卡片上没有来源的收藏显示「在新会话里修改」（右键菜单对所有收藏都有）：聊天窗口切到新会话，输入框预填 `#收藏名 `，用户写下要求后发送

### `#` 引用收藏
- 输入框里输入 `#` 按名称（支持拼音）列出收藏。Enter、Tab 或点击插入 `#收藏名`；Ctrl/⌘+Enter 或行尾按钮直接打开该收藏（快速启动）
- 发送时后台在原话里找 `#收藏名`（最长匹配，最多 3 个），把命中的收藏写进本轮附加上下文 `<referenced_artifact>`：名称、类型、在本会话里的 `artifact_key` 与入口、怎么发布新版本，以及代码（入口文件优先，每个收藏最多内联 4 万字符，二进制和超出的文件只列名）。界面只显示原话
- 会话建好后，收藏的文件放进本会话工作区 `artifacts/collection-<id>/`（目录已存在则不覆盖），模型可以用 edit_file 只改差异再 `show_artifact` 发布
- 来源：没有来源、或来源会话里已没有它的收藏，引用后改记本会话为来源（版本 0）；模型发布后合集卡片出现「↻ vN」，用户一点即把新版本写回收藏。来源会话还在时不改来源，说明里会告诉模型这里发布的是本会话的新 Artifact。在来源会话里引用时直接用原来的 `artifact_key`，不重复放文件也不内联代码
- 实现见 `src-tauri/src/artifacts/references.rs`，在 `ask_ai` 组装本轮附加上下文时调用，所有发送入口（普通发送、排队、Ask 窗口）都生效

### 绑定与隔离
- 页面只能访问宿主绑定的数据库与助手：收藏时设定的 `db_id`/`assistant_id`，或预览窗口里的临时设置。宿主 `useArtifactBridge` 不采用页面消息里的 `db_id`/`assistant_id`；页面重复传入相同的值可以，传其他值会收到错误，未绑定时传入任何值也会被拒绝
- 模板 SDK（`artifact-sdk.ts`）的 `dbId`/`assistantId` 参数只为兼容旧代码保留
- 桥接只处理所绑定 iframe 发来的消息；绑定配置（`aipp_config`）只发给 iframe 当前地址的 origin，页面跳到外站后不会再收到

### 预览路由
- `preview_router.rs` 路由预览请求
- 根据内容类型分发
- 统一预览接口

## 会话工作区

助手在会话工作区写文件后用 `show_artifact` 发布，侧栏随之列出。工作区位于 `<应用数据>/artifact_workspaces/conversation_<id>/`，删除会话时一并删除。某个已发布 Artifact 的入口文件丢失时，侧栏跳过它，其余照常列出。

### 版本

- **何时生成：** 每次 `show_artifact` 会把 `artifacts/<artifact_key>/` 整个目录固定为一个版本。版本存在会话库 `artifact_version` 表中（`src-tauri/src/artifacts/versions.rs`），随会话删除，不参与跨设备同步。
- **去重与上限：** 与上一版内容完全相同时不新增版本，只更新标题与绑定。每个 Artifact 保留最近 30 个版本。
- **快照规则：** 与比选工程相同，单版不超过 20 MiB、2048 个文件，跳过依赖与缓存目录。超出时只保存入口文件。
- **切换版本：** 有多个版本时，查看器工具栏可以切换，正在看旧版时标「旧版」。重新发布后自动回到最新版本。
- **版本号显示：** 聊天里的成果卡显示这次发布的版本号，「打开」打开的就是那一版；侧栏列表显示最新版本号。

### 多文件 Artifact

- 入口用相对路径引用同目录的其他文件时（`import './x'`、`<script src>`、`<link href>`、图片、CSS `url()`），该版本标为多文件，预览改用比选工程同款的浏览器内运行时（Babel 加 Vue 编译器，不经 Bun）。
- 运行时只能 import `react`、`react-dom/client`、`vue` 与工程内文件，也不支持 `db_id`/`assistant_id` 绑定。需要模板内置依赖或绑定时，写成单文件。
- 代码视图可以切换查看工程里的每个文件，运行报错同样进入控制台。
- 这个运行时按生产构建的 classic 脚本加载，开发模式（`tauri dev`）下无法运行，与比选卡相同。
- 需要 npm 依赖时：工程里有 `package.json` 的多文件版本，预览上方显示构建栏，填写输出目录（默认 `dist`）后「用 Bun 安装依赖并构建」。与比选工程同一流程：应用内确认框列出命令，确认后在临时副本里安装与构建（`build_artifact_version`）。构建输出存进该版本（`artifact_version.build` 列），之后卡片、分栏、独立窗口打开这一版都直接预览构建结果（`open_artifact_version_build`，同一版本共用一个预览进程）

### 模型可用的工具

- `get_artifact_workspace`、`show_artifact`、`capture_artifact_screenshot`
- `list_artifacts`：列出会话里全部 Artifact，包括已撤下的，返回最新版本与版本数
- `get_artifact`：读取任一版本的文件清单与单个文件内容（默认入口，最多 10 万字符），用来回看或恢复旧版
- `unpublish_artifact`：从侧栏撤下，文件与版本保留，再次 `show_artifact` 即恢复

除截图（会启动本机预览服务）外均免审核。

### 收藏某个版本

- 在预览窗口收藏的是当前正在看的那一版。单文件版本保存入口代码；多文件版本按比选同款工程归档保存完整文件，打开、Bun 构建与跨设备同步都沿用收藏工程的能力。
- 收藏记下本机来源（会话、`artifact_key`、版本），存在 `artifacts_collection.source` 列，不同步。合集窗口可「回到原会话继续修改」。
- 原会话里这个 Artifact 有了更新的版本时，合集卡片显示「↻ vN」。点击（或右键「更新到原会话的 vN」）把收藏内容换成最新版，名称、图标、标签和绑定不变，来源版本随之更新。由 `get_collection_source_updates` 与 `update_collection_from_source` 实现；原会话已删除的收藏不显示更新。

`capture_artifact_screenshot` 截取 React/Vue 组件时复用固定的截图模板目录（依赖只安装一次），同一时间只运行一个截图预览，截完即结束对应的预览服务。

## 比选卡中的完整工程

助手用 `artifact_key` 指定本会话 Artifact 工作区内的工程目录，用 `entry_file` 指定工程内入口。比选卡会保存入口、组件、样式、图片、依赖声明和锁文件。原工程改名、改写或删除后，仍可从历史卡回看，或将该版本发布到会话侧边栏。单次本地快照合计上限 20 MiB，每个工程最多 2048 个文件，跳过依赖安装目录、版本库和缓存。

桌面可以直接预览常用多文件 React/Vue 工程。需要 npm 包或自定义构建时，展开「工程构建」，填写静态输出目录（默认 `dist`），点击「用 Bun 安装依赖并构建」。应用内确认框列出安装命令、工程的 `build` 脚本和输出目录。确认后，本机 Bun 在快照的临时副本中安装和构建，脚本具有当前用户的文件和网络权限。输出目录需包含 `index.html`。成功后固定构建产物。卡片、全屏和独立窗口同时查看同一版本时共用一个 Bun 预览进程，关闭最后一个视图后释放进程。工程 Markdown 的相对图片随版本保存，可从历史和发布后的会话侧边栏回看。

从候选的独立预览窗口收藏时，收藏会保存该版本的内容、完整工程文件及已有的构建产物。删除原会话后，仍可从收藏打开。尚未构建的工程可以从桌面收藏窗口发起构建，每次安装和执行前都会请求确认。早期仅保存候选引用的收藏，在首次打开时从原会话补全；原快照已删除时会提示无法恢复。
