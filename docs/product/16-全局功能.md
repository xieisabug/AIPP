全局功能模块提供应用级别的功能，包括快捷键、系统托盘、应用更新、主题切换等。

## 系统 API

### system_api.rs 系统 API
- 系统信息获取
- 系统配置管理
- 剪贴板操作
- 文件对话框

### 通知功能
- 系统通知
- 通知权限请求
- 通知点击响应
- 通知历史

### AI 完成通知
- `notification_on_completion` 功能开关（“程序功能 → 显示”中的“消息完成时发送系统通知”）
- AI 响应完成后自动发送桌面通知
- 智能抑制：当 ChatUI 或 Ask 窗口处于焦点时不弹出通知
- 使用 Tauri 通知插件实现跨平台桌面通知

### Agent 完成通知
- 与 AI 完成通知共用同一个 `notification_on_completion` 开关，不再单独配置
- 覆盖 Codex、Claude Code、ACP Agent，仅在成功完成一轮任务后通知；失败、取消不通知
- 与普通 AI 完成通知一致，ChatUI 或 Ask 窗口聚焦时不弹出系统通知

### 等待审批提醒
- 需要用户亲自审批的情况：操作权限 / 管理操作批准、Agent（Codex、Claude Code、ACP、原生 Agent）权限请求，以及没有自动执行、停在待确认的 MCP 工具调用（助手未开启自动审核，或自动审核判定有风险 / 审核失败）。自动审核进行中、免审核和审核通过的调用不算
- 系统通知：`notification_on_permission` 开关（“程序功能 → 显示”中的“等待审批时发送系统通知”），**默认开启**，与完成通知互不影响。标题为“等待审批 - 助手名”，正文说明审批内容（普通会话附会话标题；工具调用附自动审核结论）
- 只在用户看不到这条审批时提醒：各窗口通过 `set_approval_surface` 上报自己正在展示哪些会话的审批（ChatUI / Ask 只展示当前会话；管家窗口为全部管家会话弹审批弹窗，工具调用确认卡片只在打开的会话里），展示了该审批的窗口都没聚焦时才弹。同一会话 10 秒内连续出现的审批只提醒一次
- 列表标识：会话列表（ChatUI）、管家联系人 / 总管家 / 群聊（按成员会话汇总）显示琥珀色待审批圆点，与未读标识同尺寸，优先于未读与“回复中”；ChatUI 会话列表里的助手小头像与管家联系人头像播放“提醒”（`alerting`）动画
- 实现：`src-tauri/src/api/approval_attention.rs`（权限请求统一经 `emit_permission_request_event` / `emit_permission_resolved_event` 登记；工具调用在 `should_auto_execute_after_review` 判定为待确认时登记、状态离开 pending 时释放）；前端 `src/hooks/useApprovalAttention.ts`（`list_pending_approval_conversations` + `approval_attention_changed` 事件）

## 防泄漏模式

### 敏感内容遮罩
- `AntiLeakageContext.tsx` 提供防泄漏上下文
- 开启后自动遮罩对话内容和标题
- 防止屏幕分享或旁人窥视时泄露敏感信息

### 临时显示控制
- `toggleReveal()` 临时显示/隐藏切换
- `resetReveal()` 重置为遮罩状态
- 关闭防泄漏模式时自动重置显示状态

### 全局配置
- 通过功能配置（feature_config）全局开关
- 设置界面中可启用/禁用
- 影响 ConversationTitle、MessageItem、ConversationUI 等多个组件

---

## 对话活动状态追踪

### 活动状态管理
- `ConversationActivityManager` 追踪对话焦点状态
- 支持三种状态：None（无活动）、Active（激活）、MCP Executing（MCP 执行中）
- 活动焦点变更时发送 `activity_focus_change` 事件

### UI 联动
- 活动状态控制 UI 元素显示（如发光边框效果）
- MCP 执行前备份当前状态，执行后恢复
- 实时反映当前对话的工作状态

---

## Logo 动画状态

### 状态类型
- `useLogoState` Hook 管理 Logo 动画状态
- 支持 5 种状态：`normal`（正常）、`happy`（开心）、`working`（工作中）、`error`（错误）、`thinking`（思考中）
- 状态切换后 2000ms 自动恢复为 normal

### 状态联动
- AI 响应中切换为 thinking/working 状态
- 错误发生时切换为 error 状态
- 提供直观的 AI 工作状态视觉反馈
