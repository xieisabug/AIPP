# 内置工具

内置工具是 MCP 工具系统的一部分，提供了一系列开箱即用的 MCP 工具，包括 Web 搜索、文件操作、Shell 执行、Agent 能力、UI 交互、Artifact 管理、动态 MCP 加载等常用功能。内置工具与外部 MCP 服务器统一管理，均使用 `aipp:` 前缀标识。

---

## Web 搜索（多引擎）

### 搜索引擎支持
- 支持多种搜索引擎：
  - **Google** - 谷歌搜索
  - **Bing** - 必应搜索
  - **DuckDuckGo** - 隐私优先搜索引擎
  - **Kagi** - 付费搜索引擎

### 智能回退策略
- 引擎管理器 `engine_manager.rs` 管理多个搜索引擎
- 主引擎失败时自动回退到备用引擎
- 默认策略：Google → Bing 回退
- 可配置引擎优先级

### 搜索结果获取与格式化
- `handler.rs` 主搜索处理器
- 搜索结果统一格式化
- 结果摘要生成
- 链接与标题提取

### 搜索配置与浏览器恢复
- 搜索工具默认总执行时限为 60 秒，Chrome 启动、导航和结果等待的默认时限同为 60 秒；导航和结果等待也计入总执行时间。旧的内置搜索 20 秒默认配置会自动升级，用户自定义超时保持不变。
- 多个搜索工具集分别读取各自的引擎配置；Kagi 工具使用 `aipp:search` 和 `SEARCH_ENGINE=kagi`，登录仍依赖用户已有的 Kagi 会话。
- Windows 启动搜索浏览器前会检查残留进程：只回收使用相同配置目录、带自动化标识且父进程已退出的 Chrome 主进程。结束前再次核对进程身份；父进程仍在、身份不确定或属于其他配置目录时不会结束它。
- 进程检查或回收失败会报告阶段、原因及相关进程/目录信息，不删除用户浏览器配置目录。

### 真人验证
- 桌面搜索和浏览器抓取平时使用无头 Chrome，不创建可见窗口。只有检测到真人验证，才启动新的普通 Chrome 窗口，重新访问原搜索/抓取地址供用户直接操作；不使用最小化常驻窗口或截图转发。
- 人工浏览器使用 AIPP 独立持久配置目录 `chromiumoxide_manual_profile`，与无头浏览器、日常 Chrome 隔离；首次可能需要登录，后续保留此人工配置的登录状态。使用与请求相同的代理配置，不复制 Cookie，不自动作答。
- 验证通过且目标结果出现后，直接读取新浏览器中的 HTML，随后关闭人工浏览器；不会把旧无头页面当成已经验证通过。
- 人工等待期间暂停 60 秒搜索执行预算，验证最多等待 5 分钟。人工配置一次只供一个调用使用，其他需要验证的调用最多排队 60 秒；正常无头搜索不受此队列影响。
- 关闭人工窗口、浏览器断开或等待到期都会终止本次验证并返回原因；停止原调用也会清理对应人工浏览器，不关闭用户日常 Chrome。
- Kagi 的辅助验证提示和封闭组件内的验证框均参与检测。网站仍可能拒绝浏览器环境，未确认出现结果时不会报告成功。

## UI交互工具

### 向用户提问（ask_user_question）
- `interaction.rs` 提供 UI 交互能力
- 用于向用户询问问题、收集偏好、澄清歧义
- 支持 1-4 个问题，每个问题 2-4 个选项
- 支持多选模式（multiSelect）
- 用户答案作为工具结果返回

### 文件预览（preview_file）
- 在专门的 UI 组件中显示文件内容或富媒体
- 支持格式：markdown、text、image、pdf、html
- 支持多文件展示：tabs（标签页）、list（列表）、grid（网格）
- 支持内联内容或 URL 引用
- 本地文件通过安全的 relay 机制访问，10 分钟过期
- 最大支持 20MB 文件

## Artifact 工作区工具

### 获取工作区（get_artifact_workspace）
- 获取当前会话的 Artifact 工作区路径和 manifest 路径
- 首次调用自动初始化目录结构
- 用于会话级 Artifact 管理

### 发布 Artifact（show_artifact）
- 将工作区中的文件显式发布为 Artifact
- 发布后更新 artifact manifest
- Sidebar 将展示该 Artifact
- 支持自定义标题、语言、预览类型等

## MCP 动态加载工具

### 加载 MCP 工具集（load_mcp_server）
- 根据关键词检索 MCP 工具集目录
- 返回对应工具集下的工具摘要
- 用于按需发现可用的 MCP 工具集

### 加载 MCP 工具（load_mcp_tool）
- 按关键词加载 MCP 工具到当前会话
- 在本次工具返回中给出描述和参数定义，不把 schema 追加进模型 `tools`
- 支持关键词或完整 `server::tool` 形式
- 可一次传入多个工具
- 可选限定在指定工具集下搜索

### 调用已加载工具（call_mcp_tool）
- 调用已经加载到当前会话的 MCP 工具
- 入参为目标工具集、工具名和参数对象
- 未加载或参数不完整时返回明确原因
- 聊天卡片、权限和审计按目标工具展示，与直接调用一致

## 移动 HTTP 抓取边界

Android 的 `fetch_url` 直接获取 HTTP/HTTPS 文档，支持 HTML、纯文本、Markdown 和 JSON，按响应 charset 解码；单次请求限时 30 秒，正文上限 4 MiB，最多 10 次重定向。拒绝内嵌账号密码的 URL、非 HTTP 协议和 HTTPS 到 HTTP 的重定向。正文过大、编码不匹配、HTTP 错误或空正文会明确报错，不返回截断内容，也不会启动浏览器补抓。

需要 JavaScript 渲染的网页不属于移动 HTTP 抓取范围。移动搜索需由用户显式配置 HTTP/SSE MCP 搜索服务；桌面 Chromium 的 `search_web` 不会自动换服务商。
