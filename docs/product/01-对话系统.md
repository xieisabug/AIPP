# 对话系统

对话系统是 AIPP 的核心功能模块，提供完整的 AI 对话交互体验。

---

## 对话创建与管理

### 创建新对话
用户可以通过多种方式创建新对话：
- 直接在 ChatUI 窗口中点击「新对话」按钮创建
- 通过 Ask 窗口提问时自动创建新对话
- 使用 `create_conversation_with_messages` API 创建带初始消息的对话
- 创建时可指定对话名称、系统提示词、用户消息等参数
- 对话会关联到选定的助手配置和模型配置
- 新对话选择 Codex 助手时，模型与思考强度优先使用助手已保存的值；未显式保存时使用 Codex `config/read` 返回的生效默认值，而不是模型目录第一项
- 新对话首页在桌面端直接展示文件提示和 !bang 命令，说明文字沿用统一小字号及居中布局；仅移动平台将这些内容收起到「高级提示」中，桌面窗口缩窄不会启用折叠。

### 对话列表展示
- 分页加载对话列表，支持分页参数（page、page_size）
- 显示对话标题、助手名称、创建时间等信息
- 使用助手名称缓存提高列表加载性能
- 打开对话时显示「正在读取对话…」，消息提交后显示「正在排版消息…」，待首帧绘制机会后关闭提示；代码高亮可继续异步完成
- 消息较少且文本总量适中的会话保留已加载的消息节点，减少滚动中的重新排版和跳动；超出规模上限的会话继续使用虚拟列表
- 通过 `conversation_created`、`conversation_deleted` 事件实时更新列表
- 流式完成时，已显示和仍在等待刷新的最后一帧都会交给最终消息，防止清理流式状态后尾部缺字；切换会话时丢弃旧会话的待刷帧和订阅回调。

### 对话删除
- 同时清理排队消息、Agent 会话映射、外部消息关联与转发记录、对应 Butler 任务定义和结果、MCP 调用与审查日志、已加载工具及插件 Hook 日志。
- 单条消息删除会清理其附件和相关调用、转发及审计记录；保留其他消息，解除可选的父消息引用。转发游标作为投递进度保留，避免重新投递旧回复。
- 支持删除整个对话及其所有消息
- 删除后发送 `conversation_deleted` 事件通知前端更新
- 级联删除对话相关的所有消息和附件

### 消息操作
- 桌面端悬停消息显示操作条（编辑、重新生成、分叉、插件操作、消息信息、导出、复制）。
- 桌面端在消息上右键弹出菜单，提供与操作条相同的功能；有选中文本时额外提供「复制选中内容」。图片等自带右键菜单的元素保持各自菜单。移动端不接管长按，操作常驻气泡底部。

### 轮次导航
- 桌面端消息区左侧有一条竖向轮次导航（私聊与管家群聊共用）：每次用户提问对应一个位置，当前阅读轮次用实心刻度标出。
- 导航高度有上限（最多约为消息区高度的一半，与消息区垂直居中，不随输入区高度变化）：提问少时逐轮画刻度；提问很多时导航不再变长，刻度自动变薄（最细 1px）并排满整条轨道，每一轮都有自己的标记，既不会漏轮也不会铺满屏幕。
- 纯附件提问（只有图片/文件、没有正文）也算一轮，同样有刻度；工具执行结果回填的消息不算提问。
- 鼠标在导航上移动时吸附到最近的一轮，旁边显示「第 i / N 轮」与提问片段，点击跳转并把该轮提问顶到视口顶部。点击导航不会抢走输入框焦点。
- 键盘可 Tab 聚焦导航：方向键逐轮、PageUp/PageDown 每次 10 轮、Home/End 首尾预览，Enter 跳转，Esc 取消预览。
- 移动端对应的是右侧轮次滑轨，见 [移动导航与预览](./20-移动导航与预览.md)。

### 对话分支（Fork）
- 支持从指定消息位置分叉新对话
- 保留原对话历史到分叉点
- 自动在标题后添加"版本N"标识
- 复制消息附件
- 同时复制的消息更新创建时间

### 对话搜索
- 支持按关键词搜索对话
- 搜索范围包括：对话标题、对话总结、消息内容
- 返回匹配结果带高亮片段（snippet）
- 标注命中类型（title/summary/message）
- 支持 limit 和 offset 分页

## 消息版本化与分支

### 消息重新生成
- 支持对 AI 响应消息重新生成
- 每次重新生成创建新的消息版本
- 使用 `generation_group_id` 标识同一次生成的消息组
- 使用 `parent_group_id` 标识父版本组，形成版本树

### 版本分页浏览
- 前端 `useMessageGroups.ts` 处理版本分组逻辑
- 支持在不同版本间切换浏览
- 版本分页组件显示当前版本/总版本数
- 提供上一版本/下一版本导航按钮

### 消息排序规则
- 按创建时间排序
- 同一 generation_group_id 中 reasoning 消息排在 response 之前
- 消息类型优先级：system > user > reasoning > response > assistant

## 流式响应

### 流式聊天实现
- 使用 genai 客户端的 ChatStreamEvent 流式接口
- 支持流式和非流式两种模式
- 流式响应实时更新消息内容

### 实时 UI 更新
- 通过 `message_update` 事件推送内容更新
- 首 Token 时间（TTFT）记录和展示
- 逐步追加内容到消息
- 实时更新 token 计数

### 响应取消功能
- 使用 CancellationToken 实现取消
- `cancel_ai` 命令中止当前生成
- 清理会话状态和任务
- 支持 ACP 会话任务中止

### 错误处理与重试
- 自动重试机制，可配置重试次数
- 普通会话在合并或非合并消息模式下都按重试尝试展示中断/完成状态，旧部分输出可展开，诊断全文可触控查看和独立复制。非合并模式仍保留每条消息的气泡与操作。
- Butler 精简结果视图不展示重试分组或诊断，沿用上游提供的结果内容；没有重试元数据的旧历史保持原样，不推测尝试编号。
- 指数退避重试延迟计算
- HTTP 错误详情提取（状态码、响应体、request_id）
- 请求失败默认折叠成一行“回复失败：概括（具体原因）· 查看详情”，具体原因取根因或服务端返回的错误说明；点开后标题行不变，下方以同样的中性样式展开详情（状态码、模型、阶段、请求 ID、端点、建议，可再展开响应体与原始错误，可复制），再点标题收起。普通聊天与管家简洁聊天使用同一个组件；之后已有回复的旧错误显示为“此前请求失败 · 查看错误”。
- 回复进行中发送的消息会排队；队列只在一轮回复结束时自动派发。会话空闲时（如重启后、上一轮报错）排队消息不会自己发出，可点消息旁的排队/打断图标选「立即发送」；会话仍在回复时会提示等待本轮结束或改用「提升为打断消息」，已被发出或已作废的消息不会重复发送。

## 对话标题生成

### 自动生成标题
- `generate_conversation_title` API 自动生成
- 使用配置的标题生成模型
- 基于对话内容智能生成简洁标题
- 普通对话、Codex、Claude Code 与 ACP 在首轮成功响应后均会尝试生成标题
- ACP 对端主动提供的会话标题优先；本地标题生成只处理空标题或“新对话”，不会覆盖自定义标题

### 手动编辑标题
- `update_conversation` API 更新标题
- 发送 `title_change` 事件通知
- 用户可随时修改对话标题

## 附件功能

### 文件附件上传
- 支持文件拖拽上传（`useFileDropHandler` 提供拖拽事件处理和视觉反馈）
- 附件与消息关联存储
- 支持多附件
- 拖拽状态跟踪和浏览器默认行为拦截
- 附件通过 SHA256 哈希去重，避免重复上传

### 图片附件支持
- 图片附件预览
- 多模态输入支持
- 自动检测文件类型（Image/Text/PDF/Word/PowerPoint/Excel）
- 图片入库前统一规整（`utils/prompt_image.rs`，不保留原图）：长边超过 2000px 按比例缩小，base64 超过 4.5 MiB 时在 PNG/JPEG 间取更小者并逐步降低 JPEG 质量、再缩小；未超限的 PNG/JPEG/GIF/WebP 原样保留；格式按文件内容识别，BMP/TIFF 等转成 PNG/JPEG；透明图保持 PNG；JPEG 按 EXIF 方向摆正。压不下来时添加附件即报错
- 发送时兜底：历史里超限或 MIME 标错的旧图片在构建请求时同样规整（结果按内容缓存），避免一张大图让该会话后续每轮都被模型服务拒绝

### 附件操作
- `add_attachment` 通过 URL 或内容添加附件
- `open_attachment_with_default_app` 使用系统默认应用打开附件
- 支持直接内容提交和文件路径引用两种方式

### 选中文本引用
- `useTextSelection` Hook 捕获系统级选中文本
- 通过 Bang 命令 `!selected_text` 将选中文本插入到对话中
- 支持跨窗口文本捕获

## Bang 命令系统

### 概述
- Bang 是动态命令替换系统，用户在输入框中输入 `!` 或 `！` 触发
- 类似 DuckDuckGo Bangs 或 Shell Bang 命令
- 输入 Bang 命令后，消息发送时由 `TemplateEngine` 解析并替换为实际内容

### 内置 Bang 命令
| 命令 | 快捷方式 | 用途 |
|------|---------|------|
| `!current_date` | `!cd` | 插入当前日期（YYYY-MM-DD） |
| `!current_time` | `!ct` | 插入当前时间（HH:MM:SS） |
| `!selected_text` | `!s` | 插入当前选中的文本 |
| `!web(URL)` | `!w` | 获取网页内容（HTML 格式） |
| `!web_to_markdown(URL)` | `!wm` | 获取网页内容（Markdown 格式） |
| `!file(path)` | - | 读取文件内容 |
| `!sub_start(text, count)` | - | 截取文本前 N 个字符 |

### 补全交互
- 输入 `!` 或 `！` 时自动弹出 `BangCompletionList` 补全下拉框
- 支持按名称和快捷方式过滤
- 键盘导航（↑↓ 箭头）、Tab/Enter 选择、Esc 关闭
- 选中后自动补全命令模板，光标定位到参数位置

### 模板引擎
- 后端 `template_engine/mod.rs` 负责解析和执行 Bang 命令
- 使用正则匹配 `[!！](\w+)(\(...)?)`  提取命令
- 支持 Text、Image、Audio 三种输出类型（Image/Audio 预留扩展）
- 同时支持中文感叹号 `！` 和英文感叹号 `!`

## 对话导出

### 多格式导出
- 支持将对话导出为 **Markdown**（`.md`）、**Word**（`.docx`）、**PDF**（`.pdf`）、**PNG**（`.png`）四种格式
- 导出前会同时读取对话消息和该对话关联的工具调用记录，保证导出内容和页面展示尽量一致
- 默认文件名使用当前对话标题，保存成功后可直接从提示中打开目标文件

### 各格式特点
- **Markdown**：保留角色标题、时间、代码块和工具调用标记，适合二次编辑、版本管理和再加工
- **Word**：由后端将 Markdown 转换为 `.docx`，保留标题、列表、表格、代码块，并尽量嵌入图片
- **PDF**：桌面端通过浏览器打印链路生成，采用 A4 页面和打印样式，避免代码块、表格、图片等内容被随意截断
- **PNG**：前端通过 `html2canvas` 将导出视图渲染为图片，适合快速截图分享和归档

### 内容处理细节
- Markdown/Word/PDF 都复用统一的 Markdown 格式化结果，避免不同格式内容不一致
- 代码块高亮由 Rust 侧 `highlight_code` / `highlight_code_for_export` 负责，Word/PDF 会保留更接近阅读场景的样式
- Word 和 PDF 导出会尝试把 Markdown 里的图片转为可嵌入内容；PNG 导出则保留当前界面主题下的视觉效果
- PNG 导出会根据当前深色/浅色主题自动选择背景色，和用户当前界面观感保持一致

### 导出选项
- 当前导出对话框提供 4 个内容开关，默认都为关闭：
- 包含系统提示词
- 包含推理过程
- 包含工具调用参数
- 包含工具执行结果
- 适合在“精简分享”和“完整归档”之间快速切换

### 导出范围
- 导出以当前对话消息集合为准，不额外提供“按分支筛选”的独立导出选项
- 若消息内容中存在工具调用提示标记，系统会尽量关联对应的工具调用记录一起导出
- 单条消息也复用了同一套导出后端，支持 Markdown / Word / PDF / PNG 的单独导出能力

### 导出对话框
- `ConversationExportDialog.tsx` 导出配置对话框
- `ConversationExportRenderer.tsx` 导出渲染组件
- `conversationExportService.ts` 统一处理保存、渲染、导出与成功提示
- 导出完成后支持一键打开目标文件

## Android 文件与输出

- 附件通过系统文档选择器授权，在授权有效期内流式复制到应用私有目录。支持 PNG/JPEG/GIF/WebP、UTF-8 TXT/Markdown/CSV/JSON；每批最多 10 个，单文件 20 MiB、合计 50 MiB。ZIP 仅供 Skills 安装，不作为模型附件；PDF/Word 尚不作为模型可解析附件。显示名称与 MIME、大小、缩略图随导入保存，重启不依赖原始文档授权。
- 取消不添加附件，单项失败不丢弃同批成功项；登记失败不会产生可发送的无效附件 ID。未授权路径不能经附件导入接口读取。
- Markdown、Word 和 PNG 通过系统“创建文档”保存；取消不报告成功。保存后可分享或打开，使用临时授权 content URI；“已调起分享”不表示接收端完成。导出文件最大 32 MiB。
- PNG 按 2 倍分辨率生成，任一边超过 8192 像素或总像素超过 1600 万时明确拒绝，建议减少消息或导出 Word/Markdown，不静默截断。
- Android PDF 采用系统打印界面中的“保存为 PDF”，不运行桌面 Chromium。界面调起不等于文件生成，取消、失败及保存结果以系统打印界面为准。包含图片时要求内嵌图片，外部图片未准备好会拒绝生成，避免静默缺图。
- 图片复制独立写入 Android 图片 URI 剪贴板，不以系统分享代替；等待图片加载完成后复制，超过 1600 万像素会拒绝额外位图分配。Android 16 上实测 Chrome 134.0.6998.135 可在可编辑网页粘贴 PNG；Google Messages 20250511_01_RC03 的测试会话提示不支持附件，不能宣称该场景可用。其他目标应用仍需确认 URI 图片粘贴兼容性。
- 分享/打开导出缓存保留 7 天，在后续导出时清理。剪贴板目录独立，当前图片持续保留，替换后旧图片至少保留 7 天；应用卸载会清除私有文件。

### 会话列表头像与菜单

会话列表在助手名称左侧显示 mini 静态头像。右键会话与悬停后的三个点按钮打开同一菜单，支持修改标题和删除；打开菜单不会切换当前会话。触屏继续支持长按菜单。
