# 首次使用引导

首次在桌面打开 AIPP，且设备上还没有可用的模型服务或已配置的管家时，应用会先打开引导。点「稍后再说」会进入聊天窗口。只关闭窗口会保留进度，可用托盘或全局快捷键继续。

## 选一种开始方式

- **躺平**适合希望直接用管家的用户。可填写服务商 Key、粘贴 AIPP 分享消息，或选择电脑上检测到的智能体。添加其他服务商时，点「完成」保存连接信息并获取模型列表。在来源页点「下一步」进入模型列表。可以手动选择主力、轻量和审核模型，或点「帮我选」按本地目录填入推荐型号。最后点「应用」验证所选模型并保存配置。
- **专家**可以添加多个来源，分别选择新对话助手、轻量模型和审核模型，再选「聊天」或「管家」作为首页。选管家时可以单独设置它使用的模型和工作区。附加组件由你勾选。

曾在其他电脑使用 AIPP 时，可以在添加来源前点「登录同步」。首次同步失败时，引导会显示具体错误。在同步设置中重试，成功后引导会继续检查这台电脑能使用的来源。API Key 尚未解锁时，按提示前往同步设置输入口令。

点击「应用」或在专家模式完成配置时，引导验证所选模型。OpenAI 兼容提供商的模型若尚未保存协议，先测试 Responses。只有网关明确拒绝该接口时才用同一模型测试 Chat Completions。遇到含义不明的 404 可手动选择请求协议，再点击应用或重试。密钥、余额、限流和超时错误直接显示。成功协议按提供商和模型保存，正式聊天直接使用。其他提供商使用自身协议，Magpie、OpenCode Go 使用其模型目录中的协议。

## 模型分工

聊天可以选择 API 或本机智能体。轻量模型负责标题、总结等辅助功能，审核模型用于工具审核。可以让 Codex 负责聊天，另选 API 做轻量和审核。Ask 使用「快速使用助手」绑定的 API 模型。

躺平与专家模式共用「帮我选」。引导从 models.dev 的目录取得各服务商报价和基础模型的评测，按聊天、轻量和审核三个角色分别选。只有评测项目、版本、数据集、指标、运行方式一致的成绩才参与同组比较。缺少可比成绩计零分，价格使用当前服务地址对应的输入和输出报价。界面显示选中的模型和需要处理的验证错误。

躺平模式下，快速使用助手和总管家开启流式输出、动态 MCP，普通模型最大输出为 32,000 tokens，较小模型按容量调低。引导开启自动压缩，窗口预算取主模型输入容量的一半，1M 模型设为 512,000，容量未知时使用 128,000。默认在扣除输出和工具预留后使用量超过 80% 时压缩。

躺平模式会保存 DeepSeek 实际返回的完整型号列表，开启「对话内联网」和「聊天窗口展示余额」。默认决策 / 审核模型优先使用验证通过的 `deepseek-flash`，工具自动安全审核沿用默认决策模型。快速使用助手采用模型自动审核，初始形象为无装饰的 AIPP 标志，已有自定义形象会保留。空闲对话自动总结默认开启，有可用总结模型时执行。

主来源通过检查后，即使某个辅助模型验证失败，也可以开始使用。完成页会显示具体影响，可以单独重试。以 DeepSeek 作为主来源且余额为零时，可点「保存配置，稍后充值」。下次从余额检查继续，无需再次输入 Key。

专家模式确认应用时，如果服务商报告推荐模型不存在，引导会按排行最多再试三个候选。完成页点「换一个」可以重新选择角色模型，或把轻量、审核模型改为「不配置」。清除单独指定的审核模型后，如果设置中另有默认决策模型，工具审核仍会使用它。

## 工作区和后台准备

躺平模式默认使用用户目录下的 `AIPP` 文件夹。AIPP Skills、find-skills、Office 编辑插件、bun 和 uv 在后台准备，可以先开始聊天。Skills 安装完成后，快速使用助手启用所有已扫描到的可用 Skills。准备进度在引导完成页、聊天或管家窗口查看，失败项可以单独重试。通过引导安装 uv 时保留终端原有的 PATH。

全部准备任务结束后，如果仍有失败项，展开聊天顶部的「N 项未完成」，点击底部的「我知道了」即可收起提醒。关闭并重新打开应用后，同一批已确认的失败项也不会再提示。

首次进入专家模式时，可以修改预填的主工作区路径。已经完成引导后手动重跑，会保留已有路径。附加组件页会检查本机已安装的组件，包括手动安装的官方 Skills。

管家模型与主工作区都已设置后，首次引导入口关闭。后续可在设置里修改首页、模型和工作区，更换总管家的原生通道时会提示重开主会话，旧会话保留在历史里。

使用本机智能体担任总管家时，可以在管家会话创建和管理定时任务，并在该会话接收结果。无人值守执行需要选择绑定了 API 模型的普通助手，以便对执行中的工具调用应用定时任务审核规则。
