# 移动导航与预览

Android 使用单个 WebView 内的 MobileShell。导航按运行平台选择，桌面窄窗口仍使用桌面窗口；宽度仅影响布局。

## 导航和聊天

- 系统返回依次关闭键盘、顶层面板、返回上一页；根页退到后台，不返回 WebView 启动历史。
- 聊天与访问过的设置页保留挂载，切页继续接收回复，保留输入、未提交设置和阅读位置。会话草稿在运行期按会话区分。
- 消息下方“更多”入口可展开编辑、重生成、复制和分叉操作；版本按钮支持触控。编辑使用全屏面板。
- 离开底部后流式回复不强制滚动，使用“回到底部”恢复阅读最新消息。键盘弹起保持历史阅读位置。

## 配置

模型、助手、MCP 配置使用移动单列布局和全屏对话框；长提示词可扩展编辑。设置分类切换保留已访问页面的输入。提供商字段分别自动保存，失败显示具体错误，待保存和失败的输入不会被外部刷新覆盖。

HTTP MCP 地址只接受 HTTP/HTTPS，认证放在请求头，值使用密码输入框。Authorization 按完整值发送（例如 `Bearer …` 或 `Basic …`），不会再次添加认证前缀。已保存的服务器可通过“测试连接”重新获取能力，失败显示底层错误。依赖桌面能力的工具和未经移动能力核验的助手保留原配置，只读展示兼容性原因。

## 收藏和静态制品

聊天菜单的收藏入口在应用内打开列表，支持搜索、详情和确认删除。代码块的预览按钮支持文本、Markdown、HTML、SVG、XML、Mermaid，以及已导入的 PNG/JPEG/GIF/WebP data 图片。

预览提供缩放、局部滚动和返回。HTML/SVG 禁止脚本，移除跳转链接、表单、嵌套页面和事件属性；图片仅从 data 内容加载。Mermaid 使用严格安全模式，输出进入无脚本的隔离框架。PDF 和 Drawio 不在此预览范围内。

## 受限 React/Vue 组件

组件只在不共享宿主源的 iframe 内运行，无 Tauri、文件、助手、数据库或凭据 API。组件请求网络、表单提交、弹窗和顶层导航均不开放，不启动 Bun、Vite、Node 或 Chromium 进程。

移动宿主页还将子框架来源限制为宿主自身，禁止导航到其他本地服务端口；原生 IPC 拒绝所有子框架请求。组件源码只交给预览框一次，框架发生后续导航时停止预览并提示重新打开。

- React：JavaScript/JSX 单文件，提供 `export default` 组件；允许导入 `react`。不接受 TypeScript、多文件工程、任意 npm 包、动态 import 或 Node API。
- Vue：单文件 `<template>` + 普通 JavaScript `<script>`（`export default`），可使用原生 `<style>`，允许导入 `vue`。不接受 `<script setup>`、外部文件、TypeScript、CSS 预处理器或 Vite 插件。
- 编译使用应用已有的 Babel standalone，React 使用锁文件中的 React 19.2.8，Vue 固定 3.5.22；依赖在构建时打包到应用，设备离线也可加载，不从 CDN 下载代码。
- 不兼容依赖、语法和运行错误显示在预览内，返回后可继续聊天。组件状态在返回前一页期间保留；打开另一个制品会重新加载预览。

React 示例：

```jsx
import { useState } from 'react';
export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>计数 {count}</button>;
}
```

Vue 示例：

```vue
<template><button @click="count++">计数 {{ count }}</button></template>
<script>export default { data() { return { count: 0 }; } };</script>
```
