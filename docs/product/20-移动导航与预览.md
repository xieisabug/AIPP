# 移动导航与预览

Android 使用单个 WebView 内的 MobileShell。导航按运行平台选择，桌面窄窗口仍使用桌面窗口；宽度仅影响布局。

## 导航和聊天

- 系统返回依次关闭键盘、顶层面板、返回上一页；根页退到后台，不返回 WebView 启动历史。
- 聊天与访问过的设置页保留挂载，切页继续接收回复，保留输入、未提交设置和阅读位置。会话草稿在运行期按会话区分。
- 消息气泡底部常驻一排紧凑的浅色操作图标，包括编辑、重生成、消息信息和复制等，首个图标与正文左边缘对齐，按可用宽度直接显示；分叉、导出和插件操作固定收进“更多”菜单，其他操作仅在放不下时收起；屏幕尺寸变化时自动重新排列。图标保留至少 44px 触控范围。版本按钮支持触控，编辑使用全屏面板。
- 离开底部后流式回复不强制滚动，使用“回到底部”恢复阅读最新消息。键盘弹起保持历史阅读位置。
- 对话轮次滑轨：手指滑动消息列表时，右侧浮现与桌面左侧导航条一致的轮次刻度（每次提问一格，当前阅读轮次高亮），停止滑动约 1.6 秒后隐藏。按住滑轨上下拖动实时显示目标轮次的提问片段，松手后该轮提问顶到屏幕顶部（保留约 8px 空隙，不露出上一条消息边缘）并短暂高亮；取消手势不跳转。仅两轮及以上提问时出现，流式输出的自动滚动不会触发显示。

## 配置

设置顶栏左侧为仅图标的返回按钮，与系统返回一致：直接退出设置页回到进入前的页面，不在设置分类间回退；有未保存修改时先确认。模型提供商、个人助手、MCP、程序功能等分类在移动端为「列表 → 详情」两级：先显示条目列表（搜索框与新增按钮同一行，条目少时只显示数量），点条目进入详情，顶栏标题显示条目名、下方小字为分类名；此时顶栏返回与系统返回先回到列表，再按一次才退出设置。MCP 列表行右侧可直接启停服务器，详情页为单列信息行、整宽「测试连接并刷新能力」按钮和紧凑的工具行（启用/自动运行开关、参数按需展开），编辑/删除收进更多菜单。表单底部的保存栏贴住屏幕底部、通栏显示。只有确实改过的助手配置才会提示「有未保存的助手配置」，改了又改回原值不算修改。设置表单不使用桌面卡片外框，直接铺满页面宽度，相邻分组以细分隔线区分。模型、助手、MCP 配置使用移动单列布局和全屏对话框；长提示词可扩展编辑。设置分类切换保留已访问页面的输入。提供商字段分别自动保存，失败显示具体错误，待保存和失败的输入不会被外部刷新覆盖。

HTTP MCP 地址只接受 HTTP/HTTPS，认证放在请求头，值使用密码输入框。Authorization 按完整值发送（例如 `Bearer …` 或 `Basic …`），不会再次添加认证前缀。已保存的服务器可通过“测试连接”重新获取能力，失败显示底层错误。依赖桌面能力的工具和未经移动能力核验的助手保留原配置，只读展示兼容性原因。

## 收藏和静态制品

聊天菜单的收藏入口在应用内打开列表，支持搜索、详情和确认删除。代码块的预览按钮支持文本、Markdown、HTML、SVG、XML、Mermaid，以及已导入的 PNG/JPEG/GIF/WebP data 图片。

预览提供缩放、局部滚动和返回。HTML/SVG 禁止脚本，移除跳转链接、表单、嵌套页面和事件属性；图片仅从 data 内容加载。Mermaid 使用严格安全模式，输出进入无脚本的隔离框架。PDF 和 Drawio 不在此预览范围内。

## 受限 React/Vue 组件

组件只在不共享宿主源的 iframe 内运行，无 Tauri、文件、助手、数据库或凭据 API。组件请求网络、表单提交、弹窗和顶层导航均不开放，不启动 Bun、Vite、Node 或 Chromium 进程。

移动宿主页还将子框架来源限制为宿主自身，禁止导航到其他本地服务端口；原生 IPC 拒绝所有子框架请求。组件源码只交给预览框一次，框架发生后续导航时停止预览并提示重新打开。

- React：JavaScript/JSX 单文件，提供 `export default` 组件；允许导入 `react`。不接受 TypeScript、多文件工程、任意 npm 包、动态 import 或 Node API。
- Vue：单文件 `<template>` + 普通 JavaScript `<script>`（`export default`），可使用原生 `<style>`，允许导入 `vue`。不接受 `<script setup>`、外部文件、TypeScript、CSS 预处理器或 Vite 插件。
- 编译使用应用已有的 Babel standalone，React 使用锁文件中的 React 19.2.8，Vue 固定 3.5.22；依赖在构建时打包到应用，设备离线也可加载，不从 CDN 下载代码。
- 不兼容依赖、语法和运行错误显示在预览内，返回后可继续聊天。组件状态在返回前一页期间保留；打开另一个制品会重新加载预览。

React 示例：

```jsx
import { useState } from 'react';
export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>计数 {count}</button>;
}
```

Vue 示例：

```vue
<template><button @click="count++">计数 {{ count }}</button></template>
<script>export default { data() { return { count: 0 }; } };</script>
```

移动聊天输入栏在正常布局中占位，消息末尾不额外保留桌面浮动输入框的 120px 遮挡补偿；最后一轮的整屏最小高度策略保持不变。

Android 键盘弹出时，移动界面适配可视区域；关闭键盘后恢复原有布局，阅读历史消息时保留当前位置。

## 启动与页面加载

启动及页面首次打开时显示全屏居中的加载提示，适配屏幕安全区、深浅色设置和减少动态效果偏好。首页准备完成后自动进入聊天。

- 助手配置等准备阶段错误，在同一轮重新生成出现回复内容后自动折叠，可展开查看此前错误；当前失败仍完整展示。
- 输入框添加附件按钮使用 40px 视觉圆环，保留 44px 触控范围。


## 本机任务与同步状态

本机任务页按所选助手的实际配置检查执行能力。不可执行的助手仍可查看，页面显示具体原因；检查中或检查失败时不能派发，执行前后端再次校验。助手或 MCP 配置变化后重新检查。

同步页在回到前台、网络恢复和状态事件到达时刷新。新的事件或保存/停止等操作结果会使旧状态读取失效，避免恢复后又显示过时状态或错误；首次读取被事件超越时仍初始化已保存的服务器设置。
