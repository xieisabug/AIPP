# 小猫形象插件（示例插件）

这是一个纯声明式（`runtime.type = "declarative"`）的 AIPP 助手形象与配饰插件示例，无需构建 `dist/main.js`，桌面端与 Android 移动端均可直接启用。

## 包含内容

- **助手形象**：
  - `cat`（小猫）：奶油色的小猫把尾巴圈在身前，一侧耳朵带着橘色花斑。脸部和花斑可分别换色，尾巴跟随花斑颜色。
- **配饰**：
  - `fish-clip`（小鱼干发卡：头部侧边发卡位，摇头晃动交互）
  - `star-glasses`（星星眼镜：脸部，悬浮摘戴动画）

## 安装方式

将整个 `cat-avatar-plugin` 目录复制到 `<AppDataDir>/plugin/cat-avatar-plugin/`，在「设置 → 插件 → 扫描插件」启用，或打包为 ZIP 在插件中心安装。
