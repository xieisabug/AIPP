# 萌宠形象与配饰包（示例插件）

这是一个纯声明式（`runtime.type = "declarative"`）的 AIPP 助手形象与配饰插件示例，无需构建 `dist/main.js`，桌面端与 Android 移动端均可直接启用。

## 包含内容

- **助手形象**：
  - `orange-cat`（小猫）
  - `cloud-bear`（云朵熊）
- **配饰**：
  - `star-glasses`（星星眼镜，脸部，悬浮摘戴动作）
  - `wizard-hat`（魔法师帽，头部，抬帽致意动作）

## 安装方式

将整个 `cute-pets-avatar-plugin` 目录复制到 `<AppDataDir>/plugin/cute-pets-avatar-plugin/`，在「插件中心」点击「扫描插件」或打包为 ZIP 安装即可。
